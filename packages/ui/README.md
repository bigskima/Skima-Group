# UI Package

Reusable Milestone 4 design system primitives live here.

This package contains generic components only:

- buttons
- fields and inputs
- badges
- state panels
- page shell
- navigation
- tables
- detail lists
- dialogs
- onboarding checklist
- workflow timeline
- financial display primitives
- resource tabs and governed action layouts through shared styles

No business-specific components belong here. Future module screens should compose these primitives
with module configuration rather than duplicating UI systems.
